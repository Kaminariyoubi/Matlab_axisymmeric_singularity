# Matlab_axisymmeric_singularity

This MATLAB project has four main files, please run them in the following order:

- main.m (Solve the equations and make the plots)
- verifyGammaOmega.m (Verify the accuracy of the solution for the equations of motion for $\gamma$ and $\omega$)
- verifyS.m (Verify the accuracy of the solution of $\gamma$ and $\omega$ obtained from the ODE of $S(t)$)
- Pathline.m (Plot the pathlines)

- Moreover, the file config.m stores the parameters.
